## How It Works

### Database Setup (One-Time)
```
1. Read RAPPID dataset → Get 9,880 train numbers
2. Read train_info.csv → Get 11,113 trains with running days
3. Cross-reference → Keep only 9,880 RAPPID trains
4. Load to database → Insert with day-of-week flags
5. Cache in memory → Ready for < 1μs lookups
```

### Route Generation (Per Request)
```
User requests: /api/routes?origin=X&destination=Y&date=2026-01-26
     ↓
For EACH train in route:
     ├─ Is it running on 2026-01-26 (Monday)?
     ├─ YES → Include in route ✅
     └─ NO → Skip (intelligent filtering!)
     ↓
Return only valid routes with available trains
```
