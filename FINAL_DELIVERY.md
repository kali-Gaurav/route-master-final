**Start Server**
```bash
python api.py
# Server runs at http://localhost:5000
# Cache warming happens automatically in background
```

**Test Endpoints**
```bash
# Health check
curl http://localhost:5000/api/health

# Get performance metrics
curl http://localhost:5000/api/performance-metrics

# Get train data

# Refresh single train

# Warm cache manually
```
