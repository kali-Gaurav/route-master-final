# 🚀 VERCEL DEPLOYMENT - QUICK CHECKLIST

## Before Pushing to Vercel:

- [x] Frontend builds without errors
  ```bash
  npm run build
  ```

- [x] dist/ folder exists with index.html
  ```bash
  ls -la dist/
  ```

- [x] api/index.py exists and is valid Python
  ```bash
  python -m py_compile api/index.py
  ```

- [x] api/requirements.txt exists with Flask dependencies
  ```bash
  cat api/requirements.txt
  ```

- [x] vercel.json is properly configured
  ```bash
  cat vercel.json
  ```

- [x] package.json has build script
  ```bash
  grep '"build"' package.json
  ```

- [x] .vercelignore exists
  ```bash
  ls -la .vercelignore
  ```

---

## Deploy to Vercel:

### 1. Push to GitHub
```bash
git add -A
git commit -m "Deploy to Vercel"
git push origin main
```

### 2. Go to Vercel & Import Project
- https://vercel.com/new
- Select your GitHub repository
- Click "Import"

### 3. Set Environment Variables
In Vercel Settings → Environment Variables:
```
IRCTC_API_KEY=<your_key>
IRCTC_API_HOST=irctc1.p.rapidapi.com
IRCTC_BASE_URL=https://irctc1.p.rapidapi.com/api/v3
IRCTC_API_TIMEOUT_SECONDS=10
```

### 4. Click "Deploy"
- Wait for build to complete
- Watch logs for any errors
- Once green ✅, your app is live!

### 5. Your App URL
```
https://<your-project>.vercel.app
```

## Troubleshoot:

- **Build Failed?** → Check logs in Vercel dashboard
- **API returning 404?** → Verify `/api/` routes in vercel.json
- **React Router not working?** → Verify rewrite for `/(.*) → /index.html`
- **Assets not loading?** → Clear browser cache
- **CORS errors?** → Check CORS headers in vercel.json
